# 세무회계 성안 유튜브 — 콘텐츠 캘린더

세무 신고 시즌을 축으로 주제를 정하고, 지침을 쌓아가며 대본을 만드는 작업 공간입니다.

## 대시보드

**https://claude.ai/code/artifact/44ad5dbc-1217-46ce-9310-e62598e42658**

| 탭 | 무엇을 하나 |
|---|---|
| **시즌 캘린더** | 11개 세무 시즌과 발행 권장일. 맨 위에 "지금 준비할 시즌"이 뜹니다 |
| **주제 · 파생** | 시즌 주제 24개 + 상시 15개. 펼치면 롱폼 구성·숏폼·이어지는 주제가 나옵니다. **주제를 직접 추가**할 수도 있습니다 |
| **시리즈** | 주제를 묶는 축. 이름을 직접 만들고 주제를 담습니다 |
| **발행 일정** | 촬영일·업로드일 관리. 업로드 날짜별로 그날 나갈 영상이 묶여 보입니다 |
| **대본 지침** | 여기 적은 내용이 모든 대본 생성에 적용됩니다 |

### 세 개의 축

| 축 | 답하는 질문 | 어디서 |
|---|---|---|
| **시즌** | 언제 올릴까 | 시즌 캘린더 |
| **시리즈** | 누구에게 이어서 보여줄까 | 시리즈 |
| **일정** | 언제 찍고 언제 올릴까 | 발행 일정 |

한 주제는 시즌에도 속하고 시리즈에도 속합니다. **주제 · 파생** 탭 위쪽에서
`시즌별` / `시리즈별` 보기를 바꿀 수 있습니다.

### 시리즈 이름은 두 가지

```
관리용 이름   최초창업 시리즈
화면 제목     사장님, 사업 처음이시죠?
```

관리용은 보드에서 찾기 위한 것이고, 화면 제목은 유튜브 재생목록 이름과 영상 제목 앞머리에 씁니다.
기본으로 세 개를 만들어 뒀습니다 — 최초창업 / 사업자 생애주기 / 상속·증여.
이름과 설명은 **시리즈** 탭에서 고치시면 됩니다.

### 촬영일 · 업로드일

주제를 펼치면 아래에 **시리즈 · 촬영일 · 업로드일** 설정 줄이 있습니다.
날짜를 넣으면 **발행 일정** 탭에 날짜별로 묶여 나타납니다.

```
2026-10-15 (수)  D-9
  S9-1  예정고지서, 그냥 내도 되는 경우와 아닌 경우
  S9-2  부가세를 미리 내는 게 손해일까
```

### 주제 직접 추가
주제 목록 맨 아래 **+ 새 주제**를 누르면 그 시즌에 주제를 넣을 수 있습니다.
**제목만 넣으셔도 됩니다.** 핵심 메시지·후킹·각도를 비워두면 대본을 만들 때 알아서 채웁니다.
직접 추가한 주제에는 점선 표시가 붙고, 삭제도 됩니다.

### 대본 만드는 두 가지 방법

**① 처음부터 만들기**
```
주제 고르기 → [대본 만들기] → 마음에 안 드는 부분을 지침으로 적기 → [다시 만들기]
```
지침이 쌓일수록 대본이 취향에 맞아집니다.

**② 내가 쓴 원고를 대본 형식으로 정리**
```
[md 파일 올리기] 또는 원고 칸에 끌어다 놓기 → [대본 형식으로 정리]
```

**문장은 그대로 둡니다.** 말투를 고치거나 요약하거나 늘리지 않습니다. 하는 일은 이것뿐입니다.

- 단락을 나누고 타임코드를 붙임
- 자막으로 쓸 문장을 원문에서 골라 `[자막]` 줄을 덧붙임
- 세법 수치 옆에 `[수치검증]`, 판단이 빈 자리에 `[촬영 전 확인]`을 덧붙임
- 오탈자와 띄어쓰기만 수정

덧붙이는 표시는 원문과 별개의 줄로 들어가고, 원문 문장은 하나도 빠지지 않습니다.
올린 원고는 칸에 그대로 남아 있어 몇 번이든 다시 정리할 수 있습니다.
`.md` `.txt`, 200KB 이하. 손댈 필요 없이 이미 완성된 대본이라면 **[그대로 대본에 넣기]**.
내용은 그대로 두고 **구조와 말투만** 대본 형식에 맞춥니다. 없는 내용을 지어내지 않고,
판단이 빠진 자리는 `[촬영 전 확인]`으로 비워 둡니다. 원고가 짧으면 억지로 늘리지 않고,
마지막에 무엇이 비어 있는지 알려줍니다.

공통 지침은 모든 편에, 편별 지침은 그 편에만 적용되며 두 방법 모두에 반영됩니다.

## 핵심 원칙

### 발행 = 마감일 − 3~4주
사업자가 검색하는 시점은 마감일이 아니라 준비를 시작할 때입니다.
마감일에 올리면 이미 자료를 세무사에게 넘긴 뒤입니다.

### 시즌 60% · 상시 40%
시즌만 하면 비수기에 채널이 죽고, 상시만 하면 검색이 몰리는 기회를 놓칩니다.

### 큰 시즌 두 개
- **5월 종합소득세** — 검색량 최대, 경쟁도 최고. 상황을 좁힌 제목으로 들어가야 합니다
- **11~12월 결산·절세** — 검색량은 작지만 타깃 적합도 최고. 채널이 작을 때는 여기가 더 효율적입니다

## 폴더 구조

```
season/
  00_세무캘린더.md        11개 시즌 일정과 발행 리드타임
  topics.json             ★ 주제 데이터 단일 소스 (시즌 11 / 주제 24 / 숏폼 파생 67)
planning/
  00_브랜드_규칙집.md      톤·화법·구성. 대본 생성 프롬프트의 뼈대
  01_상시주제_15편.md      시즌과 무관한 상시 주제 기획
  03_성과기록.md           업로드 후 성과 (조회수가 아니라 타깃 적합도 기준)
scripts/
  archive/                상시 주제 대본 15편 (롱폼 15 + 숏폼 46) — 대시보드에도 올려져 있습니다
  season/                 시즌 주제 대본이 여기 쌓입니다
guide/                    원본 기획안 (docx)
```

## 명령어

```
/yt-script S11-1        주제 ID로 대본 생성
/yt-script 결산 절세     키워드로 찾아서 생성
/yt-script              지금 발행이 임박한 시즌의 1순위 주제
```

대시보드에서 고친 내용을 로컬 파일에 옮기려면 **"보드 내용 반영해줘"** 라고 하세요.

## 대본의 진행 단계

```
대본 생성  →  검토 완료  →  촬영 완료
```

대본을 열면 위쪽에 **검토 완료** 버튼이 있습니다. `[수치검증]`과 `[촬영 전 확인]`을 채우신 뒤 누르시면
**검토 완료** 탭의 "촬영 대기"로 옮겨집니다. 거기 있는 것들이 바로 찍을 수 있는 대본입니다.

표시가 아직 남아 있는데 검토 완료를 누르시면 몇 건이 남았는지 한 번 확인합니다.
그대로 진행하셔도 되고, 목록에서도 `수치검증 3 남음` 처럼 계속 보여줍니다.

촬영을 마치면 **촬영 완료**로 넘기면 대기 목록에서 빠집니다.

## 대본에 남는 두 가지 표시

| 표시 | 의미 |
|---|---|
| `[수치검증]` | 세율·한도·기준금액 — 최신 세법 확인 필요 |
| `[촬영 전 확인]` | "저라면 이렇게 합니다"에 들어갈 판단이 비어 있는 자리 |

구조와 화법은 만들어 드리지만, **판단과 숫자는 세무사님 것**입니다.
이 둘이 채워져야 기획안이 말한 "판단해주는 세무사" 브랜딩이 완성됩니다.

## 세무 일정 주의

`season/topics.json` 과 캘린더의 마감일은 표준 일정입니다.
공휴일·주말에 따라 연장되는 해가 있고, 법인세 중간예납처럼 납부기한이 별도 고시되는 경우도 있습니다.
**발행 전 해당 연도 기준으로 확인하세요.**
