### EP01 · 개인사업자 법인전환, 언제 해야 할까
`Pillar ①+②` · 롱폼 10~12분 · **채널 간판 영상**

| 항목 | 내용 |
|---|---|
| **제목(검색)** | 매출 5억 개인사업자, 지금 법인전환 해야 할까요? |
| **썸네일(감정·판단)** | **"저라면 아직 안 합니다"** |
| **핵심 메시지 1개** | 법인전환의 기준은 매출이 아니라 **"번 돈을 회사에 남길 수 있느냐"** 이다. |
| **선정기준** | ①②③④⑤ 5/5 |

**후킹 (0~30초)**
1. (문제) "매출이 커지면 법인으로 바꾸는 게 무조건 유리할까요?"
2. (의외성) "실제로는 매출이 꽤 큰데도, 개인사업자를 그대로 유지하는 게 나은 경우가 있습니다."
3. (얻을 것) "오늘은 어떤 경우에 법인전환을 검토해야 하는지, 실제 숫자로 보여드리겠습니다."
4. (자기소개 1문장) "사업자 세무를 주로 보는 세무사 김지은입니다."

**본론**
1. 대표님들이 법인전환을 떠올리는 순간 3가지 (세율 비교표를 봤을 때 / 거래처가 법인을 요구할 때 / 주변에서 바꿨을 때)
2. 세율만 보면 답이 나오는 것처럼 보이는 이유 — 개인 6~45% vs 법인 9~24% `[수치검증]`
3. **그런데 여기서 한 가지 꼭 보셔야 합니다** — 법인 돈은 대표 돈이 아니다. 급여·배당으로 꺼낼 때 세금이 한 번 더 붙는다.
4. 실제 계산 비교: 연 이익 3억 사업자가 ① 생활비로 2억 5천을 쓰는 경우 ② 생활비 1억 + 재투자 1억 5천인 경우 → 결과가 뒤집힌다
5. 세금 외 변수: 4대보험, 성실신고, 대표 신용/대출, 거래처 요구, 인력 채용, 폐업 시 청산

**판단·결론**
- "저라면 이 세 가지를 먼저 확인합니다: ① 번 돈의 몇 %를 회사에 남기는가 ② 앞으로 2년 안에 투자·채용 계획이 있는가 ③ 지금 이익이 일시적인가 지속적인가"
- "세금만 보고 결정하시면 안 되는 이유가 여기 있습니다."

**CTA**
"본인 상황이 애매하시다면, 작년 손익계산서랑 대표님 실제 생활비를 한 번 나란히 적어보세요. 그것만 해도 답의 절반은 나옵니다."

**숏폼 파생 (4편)**
- S1 "매출 5억이면 법인으로 바꿔야 할까요?" (결론 선공개형)
- S2 "법인이 무조건 세금이 적다는 착각"
- S3 "제가 법인전환을 말리는 대표 유형 3가지"
- S4 "법인 통장 돈은 대표님 돈이 아닙니다"

### EP02 · 법인카드, 어디까지 써도 될까
`Pillar ①` · 롱폼 8~10분 · **검색 유입 최상위**

| 항목 | 내용 |
|---|---|
| **제목(검색)** | 법인카드 개인적으로 쓰면 어떻게 되나요? (실제로 걸리는 유형) |
| **썸네일** | **"대표님, 이건 걸립니다"** |
| **핵심 메시지** | 문제는 '금액'이 아니라 **'패턴'** 이다. |
| **선정기준** | ①②③④⑤ 5/5 |

**후킹**
1. "법인카드로 마트에서 장 보신 적 있으신가요?"
2. "금액이 작아서 괜찮다고 생각하시는 분들이 많은데, 실제로 문제가 되는 건 금액이 아니라 패턴입니다."
3. "오늘은 실제로 걸리는 유형과, 걸렸을 때 어떻게 처리되는지까지 말씀드리겠습니다."

**본론**
1. 법인카드 사용액의 세무상 3분류: 비용 인정 / 대표 상여 처분 / 가지급금
2. 실제로 지적받는 패턴 — 주말·공휴일 반복 사용, 자택 근처 반복 결제, 마트·백화점·주유 패턴, 심야 유흥
3. 대표 상여로 처분되면 벌어지는 일: 법인세 부인 + 대표 개인 소득세 + 4대보험까지 연쇄 `[수치검증]`
4. 애매한 것들 정리: 직원 경조사비 / 명절 선물 / 골프 / 헬스장 / 가족 식사

**판단·결론**
- "저라면 이렇게 관리합니다 — 개인 지출은 아예 개인카드로 분리하고, 애매한 건 결제 시점에 메모를 남기게 합니다. 1년 뒤에 기억나지 않는 지출은 소명이 안 됩니다."
- "세법상 가능하다고 해서 무조건 유리한 건 아닙니다. 소명 부담까지 계산에 넣으셔야 합니다."

**숏폼 파생 (3편)**
- S1 "법인카드로 마트 장보기, 됩니까 안 됩니까"
- S2 "주말에 긁은 법인카드가 위험한 이유"
- S3 "대표 상여로 처분되면 세금이 이렇게 늘어납니다"

### EP03 · 매출 10억인데 통장에 돈이 없는 이유
`Pillar ③ CASE STUDY` · 롱폼 10~12분 · **채널 정체성 결정 영상**

| 항목 | 내용 |
|---|---|
| **제목(검색)** | 매출 10억인데 왜 회사에 돈이 없을까요? |
| **썸네일** | **"10억 벌었는데 통장은 0원?"** |
| **핵심 메시지** | 이익과 현금은 다르다. 세금은 **이익에** 붙는다. |
| **선정기준** | ①②③④⑤ 5/5 |

**구조: 문제 → 분석 → 판단 → 해결** (개인정보 비식별 재구성)
1. **문제** — 매출이 3년 만에 3억에서 10억으로. 그런데 세금 고지서를 받고 대표님이 물었다. "이 돈을 어디서 내라는 거죠?"
2. **분석** — 매출채권 회수기간, 재고 증가, 설비 선투자, 대표 개인 인출. 4가지가 현금을 잠식한 경로를 하나씩
3. **판단** — "세금이 잘못 계산된 게 아니라, 돈이 회사 밖과 재고에 묶여 있었던 겁니다."
4. **해결** — 이후 도입한 것: 월 단위 이익 확인, 세금 적립 통장 분리, 대표 인출의 급여화
5. 같은 문제를 겪는 대표님들의 공통점 3가지

**판단·결론**
- "매출이 늘 때 가장 먼저 무너지는 건 회계가 아니라 현금 흐름입니다. 저라면 매출 5억을 넘는 시점에 반드시 세금 적립 통장부터 만듭니다."

**숏폼 파생 (3편)**
- S1 "10억 벌었는데 통장이 비는 이유"
- S2 "세금 낼 돈이 없다는 대표님들의 공통점"
- S3 "매출 5억 넘으면 이 통장부터 만드세요"

### EP04 · 가족에게 주는 급여, 이렇게 하면 전부 부인당합니다
`Pillar ①` · 롱폼 8~10분

| 항목 | 내용 |
|---|---|
| **제목(검색)** | 배우자·부모님 급여, 비용처리 되나요? (인정 요건 정리) |
| **썸네일** | **"이렇게 주면 전액 부인됩니다"** |
| **핵심 메시지** | 가족 급여는 **실제 근무**와 **증빙**이 전부다. |
| **선정기준** | ①②③④⑤ 5/5 |

**후킹**
1. "배우자분께 월급 드리고 계신 대표님, 계신가요?"
2. "이거 절세 방법으로 많이들 알고 계신데, 잘못 하면 절세가 아니라 가산세로 끝납니다."
3. "오늘은 가족 급여가 인정되는 조건과, 실제로 부인당하는 경우를 정리해드리겠습니다."

**본론**
1. 가족 급여가 절세가 되는 원리 (소득 분산 + 4대보험 고려) `[수치검증]`
2. 인정 요건 4가지: 실제 근무 / 업무 내용의 객관성 / 동종업무 대비 적정 급여 / 실제 지급 흐름
3. 부인당하는 전형 — 계좌로 나갔다가 그날 돌아오는 급여, 근무 실적이 없는 가족, 시세 대비 과다 급여
4. 4대보험·건강보험 피부양자 문제까지 함께 봐야 하는 이유

**판단·결론**
- "대표님들이 이 부분을 정말 많이 물어보세요. 저라면 급여를 정하기 전에 '이 사람이 가족이 아니었어도 이 돈을 줬을까'를 먼저 물어봅니다. 그 질문에 답이 되면 대부분 문제없습니다."

**숏폼 파생 (3편)**
- S1 "배우자 월급, 이렇게 주면 전액 부인됩니다"
- S2 "가족 급여 적정 금액 판단하는 기준 하나"
- S3 "급여 줬다가 다시 받으면 생기는 일"

### EP05 · 법인 대표 월급, 얼마로 잡는 게 맞을까
`Pillar ②` · 롱폼 10분

| 항목 | 내용 |
|---|---|
| **제목(검색)** | 법인 대표 급여 얼마가 적정할까요? (실제 판단 기준) |
| **썸네일** | **"300만원 vs 1,000만원"** |
| **핵심 메시지** | 대표 급여는 절세 계산이 아니라 **생활비 + 자금계획**에서 출발한다. |
| **선정기준** | ①②③④⑤ 5/5 |

**후킹**
1. "법인 만들고 나서 가장 많이 받는 질문이 이겁니다. '제 월급은 얼마로 할까요?'"
2. "인터넷에 나오는 '최적 급여' 계산기, 실제로는 잘 안 맞습니다."
3. "오늘은 제가 실제 상담에서 쓰는 판단 순서를 그대로 보여드리겠습니다."

**본론**
1. 급여를 낮게 잡을 때 생기는 일 — 법인에 돈이 쌓이고, 대표는 가지급금으로 꺼내 쓰게 됨
2. 급여를 높게 잡을 때 생기는 일 — 소득세 누진 + 4대보험 부담 `[수치검증]`
3. 실제 판단 순서: ① 대표님 실제 생활비 ② 향후 1년 자금 계획(대출·주택·투자) ③ 법인 이익 규모 ④ 배당 여력
4. 급여만으로 해결하지 않는다 — 급여 + 배당 + 퇴직금 구조로 나눠 보는 관점 (→ EP12 예고)

**판단·결론**
- "저라면 이 순서로 정합니다. 세율표부터 보지 않습니다. 대표님 생활비부터 봅니다. 급여를 세금으로만 정하면, 결국 가지급금으로 돌아옵니다."

**숏폼 파생 (3편)**
- S1 "대표 월급을 최저로 잡으면 생기는 일"
- S2 "최적 급여 계산기가 안 맞는 이유"
- S3 "대표 급여, 저는 이 순서로 정합니다"

### EP06 · 법인차 비용처리, 2026년부터 달라진 것

**본론**
1. **업종코드부터 갈린다** — 전자상거래 소매업과 구매대행업은 코드가 다르고, 창업중소기업 세액감면 적용 여부까지 달라진다 `[수치검증: 업종코드 525101~525105 분류 및 감면 적용 여부]`

3. **매출 인식 시점** — 결제일이 아니라 구매확정일 기준. 월말·연말에 걸친 주문이 문제가 되는 이유

5. **간이과세 vs 일반과세** — 국내 플랫폼 중심이면 간이가 유리한 경우가 많고, 수출·매입이 많으면 일반이 유리 `[수치검증: 간이과세 기준금액 및 매입세액 공제 제한]`
6. **가장 위험한 실수: 매출 누락** — 플랫폼·PG사·카드사 데이터가 이미 국세청에 다 들어가 있다

- "대표님들이 이 부분을 정말 많이 물어보세요. 저라면 신고 전에 딱 하나만 확인합니다. 플랫폼별 정산내역서를 전부 모아서, 국세청에 잡힌 금액이랑 맞는지 대조합니다. 여기서 안 맞으면 나머지 계산은 의미가 없습니다."

**CTA**

**숏폼 파생 (3편)**

### EP12 · 법인 돈, 급여로 가져갈까 배당으로 가져갈까
`Pillar ②` · 롱폼 10~12분 · **판단력 브랜딩 핵심**

| 항목 | 내용 |
|---|---|
| **제목(검색)** | 법인 대표, 급여와 배당 중 뭐가 유리할까요? |
| **썸네일** | **"둘 다 아닐 수도 있습니다"** |
| **핵심 메시지** | 급여·배당은 **선택이 아니라 배분**의 문제다. |
| **선정기준** | ①②③④⑤ 5/5 |

**본론**
1. 급여의 특징 — 법인 비용 인정, 4대보험 부담, 근로소득 누진 `[수치검증]`
2. 배당의 특징 — 법인 비용 불인정(이중과세 구조), 4대보험 없음, 금융소득종합과세 경계 `[수치검증: 종합과세 기준금액]`
3. 이 둘만 놓고 비교하면 답이 안 나오는 이유 — 퇴직금, 대표 신용/대출, 건강보험 피부양자, 가족 주주 구성이 함께 움직인다
4. 케이스 3개로 결론이 어떻게 달라지는지 (주택 대출 예정 대표 / 재투자 중심 대표 / 은퇴 준비 대표)

**판단·결론**
- "저라면 이 질문부터 합니다. '앞으로 3년 안에 대표님 개인 명의로 돈 쓸 일이 있습니까?' 대출이 있으면 급여 쪽으로, 없으면 배분을 조정합니다. 표 하나로 정해지는 문제가 아닙니다."

**숏폼 파생 (3편)**
- S1 "급여 vs 배당, 표로는 답이 안 나옵니다"
- S2 "대출 계획이 있으면 급여를 줄이면 안 되는 이유"
- S3 "배당에도 세금이 두 번 붙습니다"

### EP13 · 5년간 세금 감면, 놓치거나 토해내거나
`Pillar ③ CASE STUDY` · 롱폼 8~10분

| 항목 | 내용 |
|---|---|
| **제목(검색)** | 창업 세액감면, 나는 해당될까요? (놓치는 이유) |
| **썸네일** | **"5년치를 놓쳤습니다"** |
| **핵심 메시지** | 감면은 **자동으로 적용되지 않는다.** 요건은 창업 시점에 결정된다. |
| **선정기준** | ①②③④⑤ 5/5 |

**구조: 문제 → 분석 → 판단 → 해결**
1. **문제** — 창업 4년차에 상담 온 대표님. 감면 대상이었는데 한 번도 적용받지 못했다.
2. **분석** — 왜 놓쳤나: 업종 판단, 창업 지역, 나이 요건, 그리고 "신청해야 적용된다"는 사실 자체 `[수치검증: 창업중소기업 세액감면 요건·감면율]`
3. **판단** — "이건 세무대리인이 사업 내용을 알고 있어야만 잡히는 항목입니다."
4. **해결** — 경정청구로 되찾을 수 있는 범위와 한계 `[수치검증: 경정청구 기한]`
5. 감면·공제 중 사업자가 자주 놓치는 항목 정리 (고용증대, 통합투자, 중소기업 특별세액감면 등) `[수치검증]`

**판단·결론**
- "감면은 몰라서 못 받는 경우가 대부분입니다. 저라면 지금이라도 최근 5년 신고서를 꺼내서 감면 항목이 비어 있는지부터 확인합니다."

**숏폼 파생 (3편)**
- S1 "창업 세액감면, 신청 안 하면 안 나옵니다"
- S2 "지나간 세금도 돌려받을 수 있습니다"
- S3 "사업자들이 제일 많이 놓치는 감면 3가지"

### EP14 · 이런 사업자가 세무조사를 받습니다
`Pillar ①` · 롱폼 10분 · **⚠️ 공포 마케팅 절대 금지 — 담담한 톤 유지**

| 항목 | 내용 |
|---|---|
| **제목(검색)** | 세무조사는 어떤 기준으로 나오나요? |
| **썸네일** | **"불안해하실 필요는 없습니다"** ← 역발상 |
| **핵심 메시지** | 조사는 운이 아니라 **데이터의 불일치**에서 시작된다. |
| **선정기준** | ①②③④⑤ 5/5 |

**후킹**
1. "세무조사 얘기만 나오면 불안해하시는 대표님들이 많습니다."
2. "그런데 실제로는 무작위로 나오는 게 아닙니다. 대부분 이유가 있습니다."
3. "오늘은 겁주려는 게 아니라, 뭘 관리하면 되는지 말씀드리려고 합니다."

**본론**
1. 조사의 종류 구분 — 정기 / 비정기, 개인·법인 차이
2. 시스템이 보는 신호: 동종업계 대비 이익률, 신고 소득 대비 재산 증가, 매출 대비 인건비·경비 비율의 급변, 거래처 자료 불일치
3. 규모가 커질 때 자연스럽게 관심을 받는 구간 `[수치검증]`
4. 조사가 나왔을 때 실제로 필요한 것 — 결국 증빙과 일관성
5. 반대로, 평소에 하면 되는 관리 4가지

**판단·결론**
- "과도하게 겁먹으실 필요 없습니다. 저라면 이 하나만 지킵니다. 숫자가 설명 가능하면 됩니다. 설명이 안 되는 숫자가 쌓이는 게 문제입니다."

**숏폼 파생 (3편)**
- S1 "세무조사는 무작위로 나오지 않습니다"
- S2 "국세청이 보는 신호 3가지"
- S3 "겁먹기보다 이걸 관리하세요"
